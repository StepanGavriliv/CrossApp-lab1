# Лабораторна робота №1
## Практикум з крос‑платформного програмування

### Опис
Ця лабораторна робота присвячена створенню та публікації крос‑платформного застосунку на .NET 8.0.  
Мета — закріпити навички роботи з GitHub, навчитися публікувати self‑contained білди для різних операційних систем (Windows, Linux), а також перевірити запуск у контейнері Docker.  
Додатково реалізовано прапорець командного рядка `--json`, який дозволяє виводити інформацію у форматі JSON.

---

### Структура проєкту
- **CrossApp.sln** — solution.
- **src/Cli** — консольний застосунок.
- **Program.cs** — основний код програми.
- **README.md** — опис лабораторної роботи.
